# 南航物理实验助手 1.0.4

> 面向使用者的发行说明。技术性变更明细见 `CHANGELOG.md`。

Windows 上的物理实验预约辅助工具：在选课窗口开放时按你的空闲时间自动抢课，
管好在手的选课，把实验笔记（报告纸）批量下载到本机。

---

## 一、本版重点：提供 **Windows 免安装版**

以前只能用源码跑（要自己装 Python）。本版起提供打包好的 EXE：

**用打包版**

1. 下载附件 `phyexp-gui-1.0.4-win64.zip`，解压到任意目录（例如 `D:\phyexp-gui\`）；
2. 双击其中的 **`phyexp-gui.exe`** —— 抢课面板直接打开。

- 目标机器**不需要**安装 Python；首次启动约 3–5 秒，之后很快。
- **请保持解压后的整个文件夹完整**：`phyexp-gui.exe` 依赖同目录的 `_internal\`，
  只把 exe 单独拖出来是不能运行的。
- 体积说明：解压后约 229 MB（含图形界面库与登录用的浏览器驱动），压缩包约 88 MB。

**用源码**

```bash
python -m pip install -r requirements.txt
python run.py gui --grab
```

**首次使用都要登录一次**：在面板右上角点「登录」，会打开浏览器由你自己输入账号密码；
凭据只保存在本机 `%LOCALAPPDATA%\PhyExpLab\`，不经过任何第三方。
打包版与源码版共用同一份会话 —— 任一版登录过，另一版直接可用。

## 三、功能回顾（1.0.3 起已有）

### 抢课面板

- **两周网格**（5 个节次 × 14 天）：点格子 = 标记「这个时段我有空」，与「现在有没有课」无关；
  窗口未开时格子显示「未放出」属正常，照样可以先选好。
- **两种开抢方式**（按钮文案会写明当前是哪种）：
  - **立即抢课**：马上拉取实时场次并提交；
  - **定时抢课**：填好时刻（按**服务端时钟**对时），到点自动开抢，等待期间显示倒计时。
- 抢课途中**随时可停**：点「停止」后，正在发出的那一条请求结束后立即停止，不再重试、不再提交。
- 抢完弹出结果：成功 / 失败 / 没抢到的时段及原因，如实列出。

### 本周期管理列表

- **已选**：点复选框 → 「退掉勾选项」即可退课（退课前二次确认）；
- **待抢**：你设为空闲、准备抢的时段，点行尾 `×` 可从计划里去掉。

### 实验笔记下载

- 「下载实验笔记」一键批量下载 PDF（勾选哪几条就下哪几条；一条都没勾则下本周期内全部已选）。
- 存放位置：**系统的「下载」文件夹** → `实验笔记\`，文件名形如
  `01_2026-10-12_下午7、8节_分光计调节与棱镜折射率的测量（531）.pdf`，重名自动加序号，不覆盖已有文件。
- 命令行同样可用：`python run.py papers`（本周期）/ `--all`（全部已选）/ `--ids` / `--out`。

### 抢课策略（默认值即"够用"，选项都在「设置」里）

| 情况 | 默认行为 |
| --- | --- |
| 该时段有课、但提交失败或没被服务端确认 | **继续重试**（默认 10 轮 × 30 秒） |
| 该节次还没放课 | **继续重试**（到点后才放出来的情况） |
| 该节次已经满了 | **不再空等**；想等别人退课时打开「捡漏」 |
| 该节次只放了你已选过的实验 | 不再尝试（同一实验不重复选） |

### 提交方式与安全

- **默认真实提交**（会写进课表），但**每次提交前都会二次确认**（默认「否」）。
- 只想试跑：在「设置」里勾「演练模式」，则完全不发写请求，只列出"本应提交哪些"。
- 顶部常驻状态标签始终显示当前是「真实提交」还是「演练模式」。
- 每条提交都会**回读服务端确认**后才算成功；HTTP 200 但回读没看到，按未成功记录。

## 四、注意事项

- 「退掉勾选项」与「真实提交」都是**真实写操作**，会改动你的课表；两者都有二次确认。
- 抢课结果**以教务系统为准**：工具只如实转述服务端的回应，不保证一定抢到。
- **自动开抢需要本机保持运行**（面板窗口开着，或命令行进程在跑）。
- 桌面通知不保证一定被看到（勿扰模式 / 全屏程序可能吞掉）；复盘请以
  `%LOCALAPPDATA%\PhyExpLab\logs\` 下的日志为准。
- 本工具与学校无关，请遵守物理实验中心的使用规定。
