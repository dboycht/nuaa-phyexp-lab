## 1.0.5 — 2026-10-08

### 修复

- **打包版点「登录」报 `Executable doesn't exist`，无法登录**（1.0.4 的免安装版受影响）：
  打包版按"浏览器内核就在程序旁边"去找，而内核实际装在用户目录，于是找不到。
  现在按 **系统 Edge → 系统 Chrome → 自带内核** 的顺序选择；Windows 自带 Edge，
  多数电脑**无需下载任何东西**。可用环境变量 `PHYEXP_BROWSER_CHANNEL` 指定内核。
- 打包版异常不再弹原始调用栈：改为一句中文提示，完整栈写入
  `%LOCALAPPDATA%\PhyExpLab\logs\crash-<时间>.log`。

### 附件

- `phyexp-gui-1.0.5-win64.zip` —— 免安装版，解压后双击 `phyexp-gui.exe`（目标机器不需要装 Python）
- `nuaa-phyexp-lab-1.0.5.zip` —— 源码（含 `packaging/` 打包配置）

> 下载过 1.0.4 免安装版的请改用本版。离线自检：`python run.py gui --self-check`
