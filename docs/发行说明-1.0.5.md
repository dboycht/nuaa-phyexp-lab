# 南航物理实验助手 1.0.5

> 面向使用者的发行说明。技术性变更明细见 `CHANGELOG.md`。

**本版是修复版：下载过 1.0.4 免安装版（`phyexp-gui-1.0.4-win64.zip`）的请改用本版**
—— 那一版点「登录」会报 `Executable doesn't exist`，无法登录。

**系统要求**：Windows 10 / 11（64 位）。免安装版**不需要**安装 Python。

---

## 一、本版修了什么

### 1. 打包版「登录」修好了；登录改为优先使用系统浏览器（别人电脑无需装 Chrome）

- **原来为什么一点登录就报错**：登录需要驱动一个真实的浏览器内核。打包后的程序会按
  "浏览器就在程序自己旁边"去找（这是打包工具的默认假设），而内核实际装在用户目录，
  于是找不到、直接报 `BrowserType.launch: Executable doesn't exist at ...`。
  用源码方式运行不受影响，所以此前没有暴露出来。
- **现在按"最省事"的顺序挑内核**：

  | 顺序 | 使用 | 需要下载吗 |
  | --- | --- | --- |
  | 1 | 系统自带的 **Edge**（Windows 10/11 自带） | **不用**，直接登录 |
  | 2 | 系统已装的 **Chrome** | 不用 |
  | 3 | 都没有时，才询问是否下载一个独立内核 | 约 130 MB，仅一次；下载完自动继续登录 |

- 所以：**不需要**为了让本工具运行而安装 Chrome；**有 Edge 就能用**。
  只有把 Edge 也卸载掉的机器，才会走到第 3 步。
- 想指定内核（例如强制用 Chrome）：设环境变量
  `PHYEXP_BROWSER_CHANNEL=msedge` / `chrome` / `chromium`。

### 2. 出错不再只弹一屏代码

打包版没有控制台窗口，之前任何异常都会弹出一个原始的调用栈对话框。
现在改为：**一句中文提示** + 完整调用栈写入
`%LOCALAPPDATA%\PhyExpLab\logs\crash-<时间>.log`（需要排查时再打开看）。

## 二、下载与运行

**免安装版（推荐）**

1. 下载 `phyexp-gui-1.0.5-win64.zip`，解压到任意目录（例如 `D:\phyexp-gui\`）；
2. 双击 **`phyexp-gui.exe`** —— 抢课面板直接打开；
3. 首次使用点右上角「**登录**」—— 会自动打开你的 Edge（或 Chrome），
   由你自己输入账号密码；登录成功后网格会自动刷新。

- 目标机器**不需要**安装 Python；解压后请**保持整个文件夹完整**
  （`phyexp-gui.exe` 依赖同目录的 `_internal\`，单独把 exe 拖出来不能运行）。
- 解压后约 229 MB，压缩包约 88 MB。

**源码方式**

```bash
python -m pip install -r requirements.txt
python run.py gui --grab
```

源码方式同样会优先使用系统 Edge/Chrome，无需额外下载内核。

**凭据只保存在本机** `%LOCALAPPDATA%\PhyExpLab\`，不经过任何第三方。

## 三、功能一览

- **抢课面板**：两周网格点选空闲时段 → 「立即抢课」或「定时抢课」（按服务端时钟对时）
  → 抢完弹出结果；抢课途中可随时「停止」（不再重试、不再提交）。
- **本周期管理列表**：已选可勾选退课；待抢（你设为空闲的时段）可一键从计划移除。
- **实验笔记下载**：一键批量下载 PDF 到 `<下载>\实验笔记\`，重名自动加序号、不覆盖。
- **设置区**：重试轮数/间隔、演练模式、捡漏（已满时是否继续等退课）、桌面通知。
- **默认真实提交**（会写进课表），但每次提交前都会**二次确认**（默认「否」）；
  每条提交都会**回读服务端确认**后才算成功。

抢课策略与注意事项详见 1.0.3 的发行说明（功能与之一致）。
