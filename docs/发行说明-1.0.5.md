# 南航物理实验助手 1.0.5

> 面向使用者的发行说明。技术性变更明细见 `CHANGELOG.md`。

**本版是一次修复版：如果你下载过 1.0.4 的免安装版（`phyexp-gui-1.0.4-win64.zip`），请改用本版**
—— 那个版本的打包版点「登录」会报 `Executable doesn't exist`，无法登录。

---

## 一、本版修了什么

### 1. 打包版「登录」按钮不可用（已修）

- **原来为什么不行**：登录用的浏览器内核（Chromium）装在**用户目录**
  （`%LOCALAPPDATA%\ms-playwright`），而打包后的程序会按"浏览器就在程序自己旁边"去找，
  于是报 `BrowserType.launch: Executable doesn't exist at ...`。
  源码方式运行不受影响，所以此前没被发现。
- **现在怎么工作**：
  - 先复用你机器上**已有的** Chromium（源码版装过就直接能用，不重复下载）；
  - 若本机还没有，会**问一句**再下载（约 130 MB，只需一次，源码版与打包版共用），
    下载完成后**自动继续登录**；
  - 下载用的是程序自带的驱动，**不需要**你另外安装 Python 或 Playwright。

### 2. 出错不再只弹一屏代码

打包版没有控制台窗口，之前任何异常都会弹出一个原始的调用栈对话框。
现在改为：**一句中文提示** + 完整调用栈写入
`%LOCALAPPDATA%\PhyExpLab\logs\crash-<时间>.log`（需要排查时再打开看）。

## 二、下载与运行

**免安装版（推荐）**

1. 下载 `phyexp-gui-1.0.5-win64.zip`，解压到任意目录（例如 `D:\phyexp-gui\`）；
2. 双击 **`phyexp-gui.exe`** —— 抢课面板直接打开；
3. 首次使用点右上角「**登录**」，浏览器打开后由你自己输入账号密码。

- 目标机器**不需要**安装 Python；解压后请**保持整个文件夹完整**
  （`phyexp-gui.exe` 依赖同目录的 `_internal\`，单独把 exe 拖出来不能运行）。
- 解压后约 229 MB，压缩包约 88 MB。

**源码方式**

```bash
python -m pip install -r requirements.txt
python -m playwright install chromium      # 首次：下载浏览器内核
python run.py gui --grab
```

**凭据只保存在本机** `%LOCALAPPDATA%\PhyExpLab\`，不经过任何第三方。

## 三、功能一览

- **抢课面板**：两周网格点选空闲时段 → 「立即抢课」或「定时抢课」（按服务端时钟对时）
  → 抢完弹出结果；抢课途中可随时「停止」（不再重试、不再提交）。
- **本周期管理列表**：已选可勾选退课；待抢（你设为空闲的时段）可一键从计划移除。
- **实验笔记下载**：一键批量下载 PDF 到 `<下载>\实验笔记\`，重名自动加序号、不覆盖。
- **设置区**：重试轮数/间隔、演练模式、捡漏（已满时是否继续等退课）、桌面通知。
- **默认真实提交**（会写进课表），但每次提交前都会**二次确认**（默认「否」）；
  每条提交都会**回读服务端确认**后才算成功。

抢课策略、注意事项与细节，见 1.0.3 的发行说明（功能一致）。
