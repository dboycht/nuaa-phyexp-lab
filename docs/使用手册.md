# 使用手册（命令速查）

> 入口统一为 `python run.py <子命令>`。仓库根目录：`D:\code\DeepSeekHarness\nuaa-phyexp-lab`（开发副本）
> 或 `D:\code\github_repository\nuaa-phyexp-lab`（canonical）。
> 建议每次先设一次编码，避免中文输出在重定向时显示成乱码：`$env:PYTHONIOENCODING='utf-8'`

---

## 一、命令总览

| 命令 | 作用 | 是否只读 |
| --- | --- | --- |
| `version` | 查看版本与目标系统 | ✅ |
| `status` | 会话/token 有效期/数据目录/最近采集 | ✅ |
| `login` | 弹出浏览器，由你本人登录并保存会话 | ✅ |
| `logout` | 删除本地会话文件 | ✅ |
| `recon` | 登录 + 录制请求（HAR + 脱敏 JSONL） | ✅ |
| `stop` | 让运行中的 login/recon 优雅收尾（HAR 落盘） | ✅ |
| `scrub <file.har>` | HAR 脱敏（抹凭据与敏感响应体） | ✅ |
| `probe` | 脚本直连自检 + 稳态 RTT | ✅ |
| `clock` | 时钟对时（服务端 − 本地偏移） | ✅ |
| `snapshot` | 采集课程/实验项目/场次余量并落盘 | ✅ |
| `watch` | 余量监控（前台，适合几分钟） | ✅ |
| `watch-bg` / `watch-stop` | 余量监控（独立进程长跑）/ 停止 | ✅ |
| `analyze` | 分析样本：退课/被抢事件、空位存活时间 | ✅ |
| `gui` | 图形界面（PySide6 只读工作台） | ✅ |
| `elect --list` | 列出各课程**有余量**的场次（含余量/地点/是否已选） | ✅ |
| `elect --slot <id> --course <id>` | **选课**（写操作；`--dry-run` 可演练） | ✍️ 写 |
| `cancel --id <user2project_id>` | **退课**（写操作；`--dry-run` 可演练） | ✍️ 写 |
| `mine` | 我的选课记录（含退课用的 `user2project_id`） | ✅ |
| `grab` | 抢课引擎（默认 dry-run 演练） | ⚠️ **`--real` 真实提交**（写操作） |

## 二、典型流程

### 1. 首次使用（约 1 分钟）

```powershell
cd D:\code\DeepSeekHarness\nuaa-phyexp-lab
$env:PYTHONIOENCODING='utf-8'

python run.py version      # 确认能跑
python run.py login        # 弹出 Chromium，你在窗口里输入学号+密码
python run.py status       # 应显示会话已保存 + token 有效期
```

> 密码只在浏览器窗口里输入，**脚本不接触密码**；会话存在
> `%LOCALAPPDATA%\PhyExpLab\session\`（仓库之外）。

### 2. 日常：看看还有没有空位

```powershell
python run.py snapshot          # 打印每个实验项目的场次数与余量，并存一份快照
python run.py gui               # 或开图形界面，点「刷新数据」
```

### 3. 盯梢（捡漏）

```powershell
# 前台跑十几分钟（适合临时盯）
python run.py watch --interval 60 --rounds 15

# 长时间跑：独立进程，关掉终端也不受影响
python run.py watch-bg --interval 60
python run.py watch-stop        # 停止
```

样本逐轮写入 `%LOCALAPPDATA%\PhyExpLab\samples\*.jsonl`；
进度写 `logs\watch-*.log`（**长跑不依赖终端输出**，这是刻意的）。

### 4. 研究：把样本变成结论

```powershell
python run.py analyze
```

输出：退课事件（余量增加）、被抢事件（余量减少）、空位存活时间、变动排行、小时分布；
完整报告写到 `%LOCALAPPDATA%\PhyExpLab\reports\analysis-*.md`。
多个样本文件会被自动合并分析。

### 5. 抢课演练（窗口开放前后都建议先演练）

```powershell
python run.py clock                                  # 先对时，记住偏移
python run.py grab --slot <场次id> --in 60 --plan-only  # 只看计划，核对换算
python run.py grab --slot <场次id> --in 20 --max-attempts 3   # dry-run 定时演练（不发写请求）
```

### 6. 选课 / 退课（**写操作**，2026-10-07 实测可用）

```powershell
python run.py elect --list                              # 先看哪些场次有余量
python run.py elect --course 71 --slot 4971 --dry-run   # 演练：只看要做的事，不发写请求
python run.py elect --course 71 --slot 4971             # 真选课
python run.py mine                                      # 看我的选课记录与 user2project_id
python run.py cancel --id <user2project_id>             # 退课
```

- 选课提交后脚本会**自动回读服务端**核对（是否有该 `schedule_id` 的记录 + 余量是否 +1），
  并打印退课命令；**不拿 HTTP 200 当成功**。
- 🔴 **本系统成功时也返回 `status:false`**（`{"status":false,"code":200,"message":"ok"}`）——
  判据只看 HTTP 状态码与 `message`；详见 [`选课与退课.md`](选课与退课.md)。
- 写操作日志：`%LOCALAPPDATA%\PhyExpLab\logs\write-<日期>.jsonl`。

### 7. 窗口开放当天

按 [`选课窗口操作手册.md`](选课窗口操作手册.md) 执行。**写接口已落地**（2026-10-07），
当天主要是：`login` → `elect --list` 确认目标 → 需要时 `grab --real --course <id> --slot <id> --at HH:MM:SS`。
已完成的实测记录与待验项见 [`选课与退课.md`](选课与退课.md)。

### 8. 实验当天（预习答题）

按 [`答题链路.md`](答题链路.md) §五 执行：`login` → 到机位后 `recon` → 点开答题页完成作答 → `stop` → `scrub`。

## 三、数据存放（一律在仓库之外）

```
%LOCALAPPDATA%\PhyExpLab\        （可用环境变量 PHYEXP_HOME 覆盖）
├─ session\state.json    会话（Cookie + localStorage token）
├─ session\token.json    抽出的 Bearer token（含 exp 提示）
├─ recon\*.har           完整抓包（敏感：含请求体，务必先 scrub）
├─ recon\*.jsonl         脱敏请求摘要
├─ samples\*.jsonl       余量采样样本（逐轮）
├─ snapshots\*.json      场次快照
├─ reports\analysis-*.md 分析报告
└─ logs\                 watch-*.log / grab-*.jsonl / **write-*.jsonl** / sampler-*.log
```

> `write-*.jsonl` 是**每次写操作**的流水（时刻 / 动作 / HTTP 状态 / 分类 / 服务端文案）；
> 复盘"到底选上没有"只认它与 `mine` 的回读结果。

## 四、常见问题

| 现象 | 原因与处置 |
| --- | --- |
| `status` 说无 token / `probe` 返回 401 | token 过期（实测 2 小时）→ `python run.py login` 重新登录 |
| 界面/命令显示中文乱码 | 读取端编码差异，不是数据坏了 → 设 `$env:PYTHONIOENCODING='utf-8'` 再跑 |
| `recon` 抓完没有 `.har` | 直接关窗口会导致 HAR 不落盘 → 用 `python run.py stop` 收尾 |
| `snapshot` 显示某项目 0 场次 | 如实结果：该项目的排课未发布/已结束，不是程序出错 |
| `elect` 提示"没有开放学期" | 选课窗口没开（或学期配置变更）→ 等窗口开放；`elect --list` 会如实说明 |
| 选课返回 `{"status":false,...}` | **多半是成功的**（成功时就是 `false`）→ 看 `message` 与回读结果，别被字段名骗 |
| 选课/退课返回 401 | token 过期（实测 2 小时）→ `python run.py login` |
| 写操作想先试而不真做 | 加 `--dry-run`（`elect` / `cancel` 都支持），或 `grab` 不加 `--real` |
| 采样任务莫名消失 | 已改用 `watch-bg` 独立进程；若仍异常，看 `logs\watch-*.log` 的最后一行 |
