## 四、风险与合规边界

| 项 | 说明 |
| --- | --- |
| **账号凭据** | 脚本**不接收、不保存**账号密码；登录由使用者在弹出的浏览器窗口完成，脚本只持有登录后的 Bearer token |
| **凭据落盘位置** | 全部在仓库之外（`%LOCALAPPDATA%\PhyExpLab`）；HAR 与 token 属敏感文件 |
| **HAR 敏感面** | HAR 含 `Authorization`、Cookie 与**登录请求体（密码 MD5）** ⇒ 必须 `scrub` 后再分析/外传 |
| **请求频率** | 监控默认 60 秒一轮（研究期建议 60–300s）；提交最小间隔 800ms 且命中限速指数退避；**不做高频轰炸** |
| **合规** | 仅供个人学习与自助使用；预习测试**计分（占总评 20%）**，本项目**不提供代答/答案注入**；请遵守学校相关管理规定 |
| **隐私设计** | 日志与报告不含学号/姓名/openid；接口示例中的身份数值一律用占位符；开发流程含提交前隐私硬闸 |
| **失败语义** | 结果分类区分成功/已满/被拒/限速/**未知**；演练结果单独标记，**绝不当成功**；接口拿不到数据时如实说明原因，不用假数据填充 |

## 五、已知限制（技术）

1. **目标系统对脚本客户端不友好**：同域 `/landing` 与 80 端口实测返回 **412**，因此统一走 HTTPS 天目湖入口；已实测带 token 的 API 请求可用。
2. **接口调用细节**：`rest/rpc/<fn>` 的参数是**裸值**，不能加 `eq.` 前缀（加了会 404）；只有 `rest/<表>` 用 `eq./in./gte.` 过滤器。
3. **本地时钟慢约 1.3 秒**：任何"按点"的动作必须换算到服务端时刻（`grab` 已内置）。
4. **长跑任务**：会话级后台任务在本机实测会被中途终止（裸 exit 1、无 traceback），
   因此长跑一律用 `watch-bg` 独立进程 + 文件日志 + PID 落盘。
5. **界面为只读**：不含任何写操作按钮，避免误触；写能力接入后会同步补界面入口。
