# 南航物理实验助手 1.0.3

> 面向使用者的发行说明。**技术性变更明细见 `CHANGELOG.md`。**

Windows 上的物理实验预约辅助工具：帮你在选课窗口开放时按自己的空闲时间自动抢课，
管好在手的选课，并把实验笔记（报告纸）批量下载到本机。

---

## 一、下载与运行

**源码方式（本版提供的附件）**

```bash
python -m pip install -r requirements.txt
python run.py gui --grab          # 打开抢课面板
python run.py --help              # 其它子命令
```

要求：Windows 10/11 + Python 3.11 以上。

**首次使用需要登录**：在面板里点「登录」（会打开浏览器，由你自己输入账号密码）；
也可以先在命令行跑一次 `python run.py login`，面板会自动复用该会话。
凭据只保存在本机 `%LOCALAPPDATA%\PhyExpLab\`，不经过任何第三方。

## 二、本版能做什么

### 抢课面板（`python run.py gui --grab`）

- **两周网格**（5 个节次 × 14 天）：点格子 = 标记「这个时段我有空」，
  与「现在有没有课」无关；窗口未开时格子显示「未放出」属正常，照样可以先选好。
- **两种开抢方式**，按钮文案会写明当前是哪种：
  - **立即抢课**：马上拉取实时场次并提交；
  - **定时抢课**：填好时刻（按**服务端时钟**对时），到点自动开抢，等待期间显示倒计时，可随时停止。
- 抢课过程中**随时可以停**：点「停止」后，正在飞出的那一条请求结束后立即停止，不再重试、不再提交。
- 抢完弹出结果：成功 / 失败 / 没抢到的时段及原因，如实列出。

### 本周期管理列表

一个列表管完这两周的事：

- **已选**：点复选框 → 「退掉勾选项」即可退课（退课前二次确认）；
- **待抢**：你设为空闲、准备抢的时段，点行尾 `×` 可从计划里去掉。

### 实验笔记下载

- 「下载实验笔记」一键批量下载 PDF（勾选哪几条就下哪几条；一条都没勾则下本周期内全部已选）。
- 存放位置：**系统的「下载」文件夹** → `实验笔记\`，文件名形如
  `01_2026-10-12_下午7、8节_分光计调节与棱镜折射率的测量（531）.pdf`，重名自动加序号，不覆盖已有文件。
- 命令行同样可用：`python run.py papers`（本周期）/ `--all`（全部已选）/ `--ids` / `--out`。

### 抢课策略（可调，默认值即"够用"）

| 情况 | 默认行为 |
| --- | --- |
| 该时段有课、但提交失败或没被服务端确认 | **继续重试**（默认 10 轮 × 30 秒） |
| 该节次还没放课 | **继续重试**（到点后才放出来的情况） |
| 该节次已经满了 | **不再空等**；想等别人退课时，在「设置」里打开「捡漏」 |
| 该节次只放了你已选过的实验 | 不再尝试（同一实验不重复选） |

所有选项集中在面板的「设置」区；收起时仍有一行摘要说明当前设置。

### 提交方式与安全

- **默认真实提交**（会写进课表），但**每次提交前都会二次确认**（默认「否」）。
- 只想试跑：在「设置」里勾「演练模式」，则完全不发写请求，只列出"本应提交哪些"。
- 顶部常驻状态标签始终显示当前是「真实提交」还是「演练模式」，不会藏在折叠区里。
- 每条提交都会**回读服务端确认**后才算成功；HTTP 200 但回读没看到，按未成功记录。

### 「关于」

面板右上角「关于」可查看版本号、数据与下载目录、写操作边界，并能直接打开仓库或数据目录。

## 三、注意事项

- 「退掉勾选项」与「真实提交」都是**真实写操作**，会改动你的课表；两者都有二次确认。
- 抢课结果**以教务系统为准**：工具只如实转述服务端的回应，不保证一定抢到。
- **自动开抢需要本机保持运行**（面板窗口或命令行进程开着）。
- 桌面通知不保证一定被看到（勿扰模式 / 全屏程序可能吞掉）；复盘请以
  `%LOCALAPPDATA%\PhyExpLab\logs\` 下的日志为准。
- 本工具与学校无关，请遵守物理实验中心的使用规定。
